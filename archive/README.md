# Archive

This directory holds project history that is useful for auditability but not
part of normal development.

- `submission/` - Kaggle/HF submission drafts, video scripts, voiceover, and demo recordings.
- `process/` - critique rounds, iteration goals, final gate checks, and hackathon criteria.
- `deploy/hfspace-dashboard/` - the older Docker/dashboard HF Space path. The current app lives in `hfspace_gradio/`.

Do not add new runtime code here. If something in `archive/` becomes active
again, move it back to a first-class directory and update `docs/repo-map.md`.
