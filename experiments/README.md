# Experiments

This directory contains notebooks and exploratory work that should not be read
as the active scanner pipeline.

- `notebooks/reports/` - report-generation and analysis notebooks.
- `notebooks/training/` - local/Colab training notebooks that are not served directly.
- `notebooks/remote/` - Kaggle/Colab runs and remote training attempts.

Promote code from here only when it has a stable command-line entry point,
tests or a reproduction note, and updated references in `README.md` and
`docs/repo-map.md`.
